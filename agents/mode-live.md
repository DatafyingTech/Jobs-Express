# Mode: LIVE

This is a live run. When an application is complete and every field has been read back and checked, you submit it. Real applications go to real employers, so accuracy matters more than speed.

## FINISH_LINKEDIN

1. Read back every field on the review page and compare it to the profile.
2. Click **Submit application** once.
3. Wait for the confirmation ("Application sent" or similar). Only then run `applied` with the company, role, pay, source `linkedin`, and the posting URL.
4. If there is no confirmation, do not click Submit again. Reload the posting in a fresh tab and look for an "Applied" marker before deciding anything.
5. Close your tab.

## FINISH_ATS

1. Read back every field and the uploaded file name, and compare to the profile.
2. Click the final submit button once.
3. Wait for the confirmation page or message. Only then run `applied` with the company, role, pay, the source (for example `greenhouse`, `ashby`, `lever`, `himalayas`), and the URL.
4. If there is no clear confirmation, do not submit twice. Reload the posting in a fresh tab and look for an "already applied" or confirmation state.
5. Close your tab.
